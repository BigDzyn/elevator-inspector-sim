# NYC DOB Elevator Inspector Exam Simulator

This is a standalone browser-based practice exam app designed to simulate the feel of a Pearson VUE-style testing session for NYC DOB elevator inspector prep.

## What it includes

- Timed full-length exam mode
- 15-question drill mode
- Question map with answered and flagged states
- Review screen before final submission
- Category-level score breakdown
- Explanations for each answer
- No build step or dependencies

## Run it

Open `/Users/shawnraynor/Documents/nyc-dob-elevator-exam-sim/index.html` in any modern browser.

## Important note

The included questions are a starter practice bank for simulation and study structure. They are not official Pearson VUE content and should be validated against current NYC DOB, ASME A17.1/CSA B44, and related training materials before you rely on them for real exam prep.
